# 🔄 Auto Update Hosts File
Этот репозиторий использует GitHub Actions для автоматического скачивания, проверки и обновления файла hosts.txt из внешнего источника.
## 📝 Описание
Скрипт предназначен для поддержания актуальной версии файла hosts.txt. Он загружает данные с сервера [https://schakal.ru/hosts/hosts.txt](https://schakal.ru/hosts/hosts.txt) и, если файл изменился по сравнению с текущей версией в репозитории, автоматически создает коммит с обновлениями.
## ✨ Ключевые особенности
 * **Работа по расписанию (Cron):** Обновление запускается автоматически каждый день в **01:30 (UTC)**.
 * **Ручной запуск:** Поддерживается триггер workflow_dispatch, позволяющий запустить обновление вручную из вкладки *Actions* в GitHub.
 * **Отказоустойчивость:** Если сервер источника недоступен или отвечает с ошибкой, скрипт использует механизм **экспоненциальной задержки (exponential backoff)**:
   * Делает до 10 попыток скачивания.
   * Начинает с ожидания в 5 секунд, удваивая время ожидания после каждой неудачной попытки (5s, 10s, 20s и т.д.).
 * **Чистая история коммитов:** Коммит и пуш происходят *только* в том случае, если содержимое скачанного hosts.txt отличается от того, что уже есть в репозитории.
## ⚙️ Как это работает
Workflow состоит из одной джобы (download-and-commit), которая выполняет следующие шаги:
 1. **Checkout:** Клонирует репозиторий с историей коммитов.
 2. **Инициализация:** Проверяет наличие файла hosts.txt. Если его нет (например, при самом первом запуске), создает пустой файл-заглушку.
 3. **Загрузка (Curl + Backoff):** Пытается скачать актуальный файл. Ограничение по времени на одну попытку — 30 секунд. В случае успеха файл перезаписывается.
 4. **Коммит и Пуш:** Сравнивает статусы Git. Если изменения есть, бот github-actions[bot] делает коммит с сообщением *"Auto-update hosts file"* и отправляет изменения в ветку.
## 🛠 Настройка репозитория
Чтобы данный workflow работал корректно, необходимо убедиться, что у GitHub Actions есть права на запись (Push) в репозиторий.
 1. Перейдите в настройки репозитория: **Settings** -> **Actions** -> **General**.
 2. Прокрутите вниз до раздела **Workflow permissions**.
 3. Убедитесь, что выбрана опция **Read and write permissions**.
 4. Сохраните изменения (кнопка *Save*).
## 📄 Файл Workflow
Код автоматизации находится по пути .github/workflows/update-hosts.yml (или под другим именем, которое вы задали). Вы можете изменить время запуска, изменив строку cron: cron: "30 1 * * *". Для справки по синтаксису cron можно использовать сайт crontab.guru.
